#Terminal Version 1.0
This is a working game of tic tac toe, which can be played in the terminal.
This is backend only which can be played by 2 players in the terminal.
Created from python.

#What's in the folder
1. app.py is the game
2. README.md is this file

#Requirements
1. coding terminal
2. python 3.8+
3. dual-core CPU, 2 GB to 4 GB of RAM, 200 MB to 10 GB of free storage (depending on packages and your OS), and a supported 64-bit operating system (Windows, macOS, or Linux)

#Run It
1. Open on VSCode
2. Run on terminal
